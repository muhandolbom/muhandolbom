# 양평군무한돌봄센터 — 의료돌봄 통합사업 앱 설치 안내

## 📁 파일 구성
```
무한돌봄앱/
├── index.html        ← 메인 앱
├── manifest.json     ← PWA 설정
├── sw.js             ← 오프라인 지원
├── icons/
│   ├── icon-192.png  ← 앱 아이콘 (소)
│   └── icon-512.png  ← 앱 아이콘 (대)
└── README.txt        ← 이 파일
```

---

## 🚀 무료 배포 방법 (GitHub Pages — 권장)

### 1단계. GitHub 계정 만들기
https://github.com 접속 → 무료 회원가입

### 2단계. 새 저장소 만들기
- 우측 상단 [+] → New repository
- Repository name: `muhando-care` (영문)
- Public 선택 → Create repository

### 3단계. 파일 업로드
- [uploading an existing file] 클릭
- 폴더 안 파일 4개 모두 드래그 업로드
  (index.html, manifest.json, sw.js, icons 폴더)
- [Commit changes] 클릭

### 4단계. GitHub Pages 활성화
- 저장소 상단 [Settings] 탭
- 좌측 메뉴 [Pages]
- Source: Deploy from a branch
- Branch: main / (root) 선택 → Save

### 5단계. 앱 주소 확인
약 1~2분 후 아래 주소로 접속 가능:
https://[내계정명].github.io/muhando-care/

## 📱 스마트폰 설치 방법

### 아이폰 (Safari 필수)
1. Safari로 앱 주소 접속
2. 하단 공유버튼(□↑) 탭
3. '홈 화면에 추가' 선택
4. '추가' 탭 → 완료!

### 안드로이드 (Chrome)
1. Chrome으로 앱 주소 접속
2. 화면 하단에 '설치하기' 배너 탭
   (또는 메뉴(⋮) → '앱 설치')
3. '설치' 탭 → 완료!

## ✅ 앱 특징
- 설치 후 인터넷 없이도 사용 가능 (오프라인 지원)
- 홈 화면에 아이콘 생성 (앱처럼 실행)
- 주소창 없이 전체화면으로 실행
- 저장된 명단은 각 기기에 보관
- 업데이트 시 자동 반영
